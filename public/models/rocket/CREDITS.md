# COSMIC X rocket model

The Saturn V GLB is sourced from NASA's official [NASA-3D-Resources repository](https://github.com/nasa/NASA-3D-Resources/tree/master/3D%20Models/Saturn%20V). The model file is `saturn-v.glb`.

NASA states that its 3D model geometry and related media are generally not subject to U.S. copyright. Follow the current [NASA Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/): NASA names and insignia are protected, and use must not imply NASA endorsement. This game is an unofficial parody.
